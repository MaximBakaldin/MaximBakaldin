# Семейный бюджет

React + TypeScript + Supabase. Совместные доходы и расходы, месячный план-факт, история, CSV-экспорт, приглашения семьи и установка на телефон как PWA.

## Разработка

Node.js 24. `npm ci`, затем `npm run dev`. Без `.env` работает локальный бюджет с сохранением в браузере. Для общей базы скопируйте `.env.example` в `.env` и заполните публичные параметры Supabase. Секретные серверные ключи не используйте.

Для новой базы выполните `supabase/schema.sql` один раз. Существующие базы обновляйте отдельными миграциями. Приложение требует подтверждения email, если оно включено в Supabase.

`npm run check` проверяет типы, lint, тесты и сборку. Тесты изолированы от реального Supabase.

## GitHub Pages

Корневой workflow `.github/workflows/family-budget-pages.yml` публикует интерфейс. В Settings → Pages выберите GitHub Actions. В Variables репозитория задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (только публичный publishable/anon ключ).

В Supabase Auth → URL Configuration укажите полный HTTPS-адрес публикации в Site URL и Redirect URLs, включая путь и завершающий слеш. Workflow автоматически определяет путь Pages.

## Установка на телефон

Android: откройте сайт в Chrome и нажмите «Установить», если доступно, либо меню ⋮ → «Установить приложение»/«Добавить на главный экран».

iPhone: откройте сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Для совместного бюджета нужен интернет. Каждый участник регистрируется в приложении по email и присоединяется к семье по одноразовому коду. Аккаунты GitHub и панели Supabase участникам не нужны.

Финансовые данные хранятся в Supabase с RLS. Кэш PWA хранит статическую оболочку, офлайн-очереди облачных изменений нет. Резервные копии настраиваются отдельно; CSV не заменяет полную копию.
