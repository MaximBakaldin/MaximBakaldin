# Версия 0.6.2 — быстрый выбор категорий

Над выпадающим списком категорий в форме операции показаны до шести кнопок — два ряда по три. Нажатие сразу выбирает категорию, заполняет поле списка и подсвечивает кнопку. Доходы и расходы имеют отдельные наборы.

Порядок определяется количеством операций всей семьи за всю историю, а не суммами. Если использованных категорий меньше шести, набор дополняется доступными категориями в обычном порядке. Архивные категории в кнопки не попадают. Удаление и редактирование операций учитываются при следующем открытии формы. При недоступности статистики сохраняется обычный список быстрых категорий и поиск.

Добавлена функция `popular_categories(uuid)` с SECURITY INVOKER и действующими RLS-политиками. У anon нет права EXECUTE. Миграция Supabase: `20261021180946 popular_categories`; локальный файл `20261021180753_popular_categories.sql`.

Проверки: TypeScript, ESLint, 91 тест, production-сборка. Тесты покрывают подсчёт по всей истории, удаление операций, отбор шести активных категорий, синхронизацию кнопок и списка, оба вида операций, доступ обоих участников семьи и отсутствие доступа другой семьи/anon. Миграционный тест сохраняет прежние данные. В действующей базе сверены агрегированные количества и права функции. Новых замечаний security advisor нет; прежние замечания описаны в [RELEASE_0.5.md](RELEASE_0.5.md).

Изолированный Chrome: 320/390 px, выбор касанием, кнопки выше списка, сохранение без прокрутки, отсутствие переполнения/ошибок JavaScript. Проверены уменьшение окна и эмуляция visualViewport при экранной клавиатуре.

Сохраняются изменения 0.6.1: свободная сумма после резервирования обязательных платежей и новый порядок навигации.
