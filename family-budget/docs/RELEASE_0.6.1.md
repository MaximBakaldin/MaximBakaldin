# Версия 0.6.1 — свободные деньги и порядок разделов

«Свободно за месяц» теперь учитывает ещё не оплаченные обязательные платежи выбранного месяца:

**Доходы − расходы − обязательные к оплате − пополнения накоплений + снятия из накоплений.**

Оплаченные обязательства уже входят в расходы. При оплате или отмене оплаты свободная сумма не меняется. Удалённые неоплаченные шаблоны не резервируют деньги. При нехватке средств отображается отрицательная сумма. Подсказка обновлена.

Основная навигация: **Главная → Бюджет → + → Анализ → Настройки**.
Вкладки бюджета: **Обязательные → Накопления → Лимиты**. При первом открытии бюджета выбраны обязательные платежи; переходы с показателей главной по-прежнему открывают соответствующую вкладку.

Проверки: 87 тестов, TypeScript, ESLint, production-сборка. Новые сценарии проверяют резервирование обязательств, отсутствие двойного вычитания при оплате/отмене, учёт переводов и отрицательный остаток. Изменений схемы базы нет.
